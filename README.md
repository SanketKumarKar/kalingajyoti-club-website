# KalingaJyoti - Odisha Cultural Club

KalingaJyoti is dedicated to preserving and promoting Odisha's rich cultural heritage through dance, music, art, and community events.

## Project Setup Instructions

1. Clone the repository:
   ```bash
   git clone https://github.com/SanketKumarKar/kalingajyoti-club-website.git
   ```
2. Navigate to the project directory:
   ```bash
   cd kalingajyoti-club-website
   ```
3. Open `index.html` in your preferred web browser to view the website.

## Usage Instructions

- Navigate through the website using the navigation bar.
- Explore different sections like Home, About, Events, Team, and Contact.
- Join our community by filling out the registration form in the Contact section.

## Contribution Guidelines

We welcome contributions to improve the website. To contribute, follow these steps:

1. Fork the repository.
2. Create a new branch for your feature or bugfix:
   ```bash
   git checkout -b feature-name
   ```
3. Make your changes and commit them with descriptive messages:
   ```bash
   git commit -m "Add feature-name"
   ```
4. Push your changes to your forked repository:
   ```bash
   git push origin feature-name
   ```
5. Create a pull request to the main repository.

Thank you for contributing to KalingaJyoti!
